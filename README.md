# Практична робота №7

## Тема
Розробка додатків з використанням елементів управління.

## Опис роботи
У межах практичної роботи створено Windows Forms-додаток для обчислення вартості замовлення в кафе.

У програмі реалізовано:
- вибір страв за допомогою CheckBox;
- вибір виду чаю за допомогою RadioButton;
- вибір додаткової начинки для піци;
- автоматичний перерахунок загальної вартості замовлення;
- можливість застосування знижки 10%;
- відображення зображень вибраних страв у PictureBox;
- активацію додаткових параметрів лише після вибору відповідної страви.

## Середовище розробки
- Visual Studio 2022
- C#
- Windows Forms
